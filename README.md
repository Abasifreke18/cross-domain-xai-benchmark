# Cross-Domain XAI Benchmark Framework

This repository contains the implementation files and experimental resources for the research paper:

"Cross-domain XAI benchmarks: Developing unified evaluation suites that assess explanation quality across healthcare and financial domains."

## Overview
This study proposes a unified evaluation framework for benchmarking explainable artificial intelligence (XAI) methods across healthcare and finance domains.

The framework evaluates explanation quality using four metrics:
- Fidelity
- Stability
- Simplicity
- Relevance

## Explainability Methods
- SHAP (SHapley Additive exPlanations)
- LIME (Local Interpretable Model-Agnostic Explanations)

## Machine Learning Model
- Random Forest Classifier

## Datasets
- Breast Cancer Wisconsin Dataset
- Credit Card Fraud Detection Dataset
